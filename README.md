# McE. Check-in

ระบบเช็คอิน–เช็คเอาท์หน้างานด้วย **GPS จริง** พร้อมใบสั่งงาน
เป็นเว็บแอปไฟล์ล้วน (static) ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีฐานข้อมูล — เอาขึ้น GitHub Pages แล้วใช้ได้เลย

---

## มีอะไรบ้าง

- **เช็คอิน / เช็คเอาท์ ด้วยพิกัดจริง** — อ่านตำแหน่งจาก `navigator.geolocation` คำนวณระยะห่างจากจุดลงเวลาแบบ Haversine ถ้าอยู่นอกรั้วพิกัดปุ่มจะล็อกพร้อมบอกว่าห่างกี่เมตร
- **แสดงพิกัดจริงให้เห็น** — ละติจูด ลองจิจูด ความแม่นยำ (±เมตร) เวลาที่อ่านล่าสุด และเรดาร์แสดงตำแหน่งเราเทียบกับไซต์
- **ใบสั่งงาน** — สร้าง แก้ไข ลบ ผูกใบงานกับการลงเวลา ปิดงานอัตโนมัติเมื่อเช็คเอาท์
- **เพิ่มพนักงานเองได้** — เพิ่ม/แก้ไข/ลบชื่อ สลับว่า "ฉันคือใคร" ได้ตลอด
- **เพิ่มไซต์เองได้** — กดปุ่มเดียวเพื่อ **ใช้ตำแหน่งปัจจุบันเป็นพิกัดไซต์** ตั้งรัศมีรั้วพิกัดต่อไซต์ได้
- **ประวัติ + ส่งออก CSV** — เปิดใน Excel ได้ทันที (มี BOM ภาษาไทยไม่เพี้ยน)
- **ติดตั้งลงหน้าจอโฮมได้** — มีไอคอน เปิดแบบเต็มจอเหมือนแอปจริง ใช้งานต่อได้แม้เน็ตหลุด
- **ไม่มีระบบเงินเดือน / OT / ใบลา** — ตัดออกตามที่ต้องการ

> ข้อมูลทั้งหมดเก็บใน `localStorage` ของเครื่องนั้น ๆ เท่านั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์
> แต่ละเครื่องจึงมีข้อมูลของตัวเอง — เหมาะกับการทำเดโม ถ้าจะใช้จริงหลายคนพร้อมกันต้องต่อฐานข้อมูลเพิ่ม

## 1) เอาขึ้น GitHub Pages

### วิธีที่ง่ายที่สุด (ลากไฟล์ผ่านเว็บ ไม่ต้องใช้ command line)

1. เข้า <https://github.com/new> ตั้งชื่อ repo เช่น **`mce-checkin`**
   - เลือก **Public** (ถ้าเป็น Private ต้องใช้ GitHub Pro ถึงจะเปิด Pages ได้)
   - กด **Create repository**
2. ในหน้า repo กด **Add file → Upload files**
3. **ลากไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไป** (รวมโฟลเดอร์ `icons/` ด้วย)

   ต้องมีครบ 8 รายการนี้:
   ```
   index.html
   styles.css
   app.js
   manifest.webmanifest
   sw.js
   .nojekyll
   README.md
   icons/          (5 ไฟล์ .png)
   ```
   > ถ้าเบราว์เซอร์ไม่ยอมให้ลากโฟลเดอร์ ให้อัปโหลดไฟล์ชั้นนอกก่อน แล้วค่อยกด
   > **Add file → Create new file** พิมพ์ `icons/x` เพื่อสร้างโฟลเดอร์ แล้วอัปโหลดรูปเข้าไป
4. กด **Commit changes**
5. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / โฟลเดอร์ **`/ (root)`** → **Save**
6. รอ 1–2 นาที แล้วรีเฟรช จะได้ลิงก์หน้าตาแบบนี้:

   ```
   https://<ชื่อผู้ใช้github>.github.io/mce-checkin/
   ```

เปิดลิงก์นี้ในมือถือได้เลย — GitHub Pages เป็น HTTPS อยู่แล้ว **GPS จึงทำงาน**

### ถ้าถนัด command line

```bash
cd mce-checkin
git init
git add .
git commit -m "McE. Check-in"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/mce-checkin.git
git push -u origin main
```
แล้วไปเปิด **Settings → Pages** ตามข้อ 5 ด้านบน

### หมายเหตุสำคัญ

- **ต้องเป็น HTTPS เท่านั้น** เบราว์เซอร์ถึงจะยอมให้เว็บอ่าน GPS — GitHub Pages ให้มาอยู่แล้ว
  (ถ้าเปิดไฟล์ `index.html` จากเครื่องตรง ๆ แบบ `file://` GPS จะไม่ทำงาน)
- ไฟล์ `.nojekyll` มีไว้กัน GitHub Pages ประมวลผลไฟล์แปลก ๆ **อย่าลบ**
- ทุก path ในโค้ดเป็นแบบ relative (`./`) จึงรันใต้ `/mce-checkin/` ได้โดยไม่ต้องแก้อะไร

## 2) ติดตั้งไอคอนลงหน้าจอโทรศัพท์

### iPhone / iPad (Safari)

1. เปิดลิงก์ Pages ด้วย **Safari** (ต้อง Safari เท่านั้น Chrome บน iOS ทำไม่ได้)
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) ตรงแถบล่าง
3. เลื่อนลงเลือก **เพิ่มไปยังหน้าจอโฮม / Add to Home Screen**
4. แตะ **เพิ่ม** → ไอคอน McE. สีดำ-เขียวมะนาวจะไปอยู่บนหน้าจอโฮม

เปิดจากไอคอนจะได้แบบเต็มจอ ไม่มีแถบ URL
ครั้งแรกที่กดเช็คอิน iOS จะถามสิทธิ์ตำแหน่ง → เลือก **อนุญาตขณะใช้แอป**

### Android (Chrome)

1. เปิดลิงก์ Pages ด้วย **Chrome**
2. มักจะมีแถบ **"ติดตั้งแอป"** เด้งขึ้นมาเอง — หรือไปที่แท็บ **ตั้งค่า** ในแอปแล้วกดปุ่ม **ติดตั้งแอป**
3. ถ้าไม่ขึ้น: แตะเมนู **⋮** มุมขวาบน → **ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก**

### อยากเปลี่ยนไอคอนหรือชื่อแอป

- ไอคอน: แทนไฟล์ในโฟลเดอร์ `icons/` โดยใช้ **ขนาดและชื่อไฟล์เดิม**
- ชื่อที่ขึ้นใต้ไอคอน: แก้ `"short_name"` ใน `manifest.webmanifest`
  และ `<meta name="apple-mobile-web-app-title">` ใน `index.html`
- หลังแก้แล้วให้เปลี่ยนเลข `VERSION` ใน `sw.js` (เช่น `v1.0.1`) เพื่อไล่แคชเก่าออก

## 3) วิธีใช้ตอนเดโม

1. เปิดแอป → แตะแท็บ **ตั้งค่า** → กด **ใส่ข้อมูลตัวอย่างสำหรับเดโม**
   จะได้พนักงาน 3 คน ใบงาน 2 ใบ และ **ไซต์ที่ใช้ตำแหน่งจริงของคุณตอนนั้น**
   (พร้อมไซต์ทดสอบอีกอันที่อยู่ห่างออกไป ~1 กม. ไว้โชว์ตอนที่ปุ่มโดนล็อก)
2. แตะไอคอนคนมุมขวาบนเพื่อเลือกว่า **คุณคือใคร**
3. กลับไปแท็บ **ลงเวลา** → เลือกจุดลงเวลา → ถ้าอยู่ในรัศมี การ์ดจะเป็นสีเขียว
4. กด **เช็คอิน** → บันทึกเวลา + พิกัด + ระยะห่างจริง
5. สลับจุดลงเวลาไปที่ "ไซต์ทดสอบ" → การ์ดเปลี่ยนเป็นสีแดง ปุ่มถูกล็อก พร้อมบอกระยะห่าง
6. แท็บ **ประวัติ** → กด **ส่งออก CSV** เพื่อโชว์ข้อมูลที่เก็บได้

**เคล็ดลับตอนเดโม**

- ถ้าต้องเดโมในห้องประชุมที่ GPS หยาบ ให้เพิ่มรัศมีรั้วพิกัดเป็น 150–300 ม. ในแท็บตั้งค่า
- ถ้าอยากโชว์ว่า "กดได้แม้อยู่นอกพื้นที่แต่ระบบจดไว้" ให้ปิดสวิตช์ **บังคับให้อยู่ในรัศมี**
- ก่อนเดโมจริง กด **สำรองข้อมูล** เก็บ JSON ไว้ ถ้าเผลอกดล้างจะกู้คืนได้

## 4) โครงไฟล์

```
mce-checkin/
├─ index.html              โครงหน้าจอทั้งหมด
├─ styles.css              ธีม E — ครีม/ดำ/ส้ม/น้ำเงิน/เขียวมะนาว
├─ app.js                  ตรรกะทั้งหมด: GPS, geofence, ใบงาน, ข้อมูล
├─ manifest.webmanifest    ชื่อ + ไอคอน สำหรับติดตั้งลงหน้าจอโฮม
├─ sw.js                   service worker — ใช้งานต่อได้เมื่อเน็ตหลุด
├─ .nojekyll               ปิดการประมวลผลของ GitHub Pages
└─ icons/
   ├─ icon-192.png
   ├─ icon-512.png
   ├─ icon-maskable-512.png
   ├─ icon-1024.png
   └─ apple-touch-icon.png
```

ไม่มี dependency ไม่มี build step — แก้ไฟล์แล้ว push ได้เลย

## 5) ข้อจำกัดที่ควรรู้ก่อนเอาไปใช้จริง

| เรื่อง | ตอนนี้ | ถ้าจะใช้จริงต้องทำอะไร |
|---|---|---|
| ที่เก็บข้อมูล | `localStorage` ในเครื่องแต่ละคน | ต่อฐานข้อมูล (Firebase / Supabase / API ของบริษัท) |
| ความปลอดภัย | ไม่มีระบบล็อกอิน ใครเปิดลิงก์ก็ใช้ได้ | เพิ่มการยืนยันตัวตน |
| การปลอมตำแหน่ง | เชื่อค่าจาก GPS ของเครื่องตรง ๆ | ตรวจ mock location ฝั่งเซิร์ฟเวอร์ / เพิ่ม QR ที่หน้างาน |
| ความแม่นยำ | ในอาคารอาจคลาด 20–100 ม. | ตั้งรัศมีให้เผื่อ หรือใช้ QR/NFC ควบคู่ |
| หลายคนพร้อมกัน | ต่างคนต่างข้อมูล | ต้องมี backend |
